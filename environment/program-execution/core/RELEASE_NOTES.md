# Program Execution System v2.0.0

This release realigns the Program Execution Blueprint and Program Execution Controller as one coherent reusable system.

The Blueprint is the immutable-at-import definition authority. The Controller is the runtime execution and evidence authority. The Controller may narrow the Blueprint, never widen it, and may recommend but never declare the terminal Program Verdict.

Major additions include deep schemas, typed targets, machine-readable ownership/state/authorization/evidence laws, exact Source and Rendered Contracts, wave enforcement, Program Lock drift detection, evidence-bound decisions and Unknowns, scoped waivers, independent verification, recovery receipts, and a canonical Handoff Receipt.
