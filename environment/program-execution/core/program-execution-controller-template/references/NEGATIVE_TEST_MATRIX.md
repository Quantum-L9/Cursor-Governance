# Negative Test Matrix

The suite must reject:

- Blueprint contract mismatch or source drift;
- missing target registration;
- duplicate authority;
- dependency cycle;
- Source Contract action inflation;
- risk-tier downgrade;
- path traversal, `.git`, controller internals, or symlink scope escape;
- dirty or changed repository state;
- lease conflict or expiry;
- expired or scope-mismatched approval;
- worker changed-file omission or invention;
- validation claim disagreement;
- gate PASS without evidence;
- implicit or expired waiver;
- ledger or manifest tampering;
- remote action without adapter and exact approval.
