# Output discipline

Governs every reply while this governance source of truth is active. One contract for all work. No per-document form.

- First line is the outcome.
- Keep a sentence only if deleting it would change what the reader believes or does.
- Do not restate the question, the plan, or a prior sentence.
- Do not print an empty heading. Use a label only when that fact exists.
- When they exist, keep four kinds of fact in any shape: what is true, what must change, what else moves, what is unknown. Drop a kind that is empty.
- Say `UNKNOWN` or `NOT RUN` once.
- Point at a skill for a procedure. Do not paste the procedure.
- This outranks essay style, and rule 05's demand to explain fully, on length only. It does not outrank law, safety, or an explicit request for the long form.
