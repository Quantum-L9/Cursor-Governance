# Section Contract — 30 Claude blocks (0–29)

All sections are required in the emitted manifest. `not_applicable` needs an explicit reason.

| # | Section | Fail-closed rule | Claude fill |
|---|---|---|---|
| 0 | Resume-From | Missing/unrunnable = reject | branch + target validation + predecessor proof |
| 1 | Mandate | Missing = reject | one focused contract |
| 2 | Prerequisite Contract | Broken seam = HALT | internal prior contract `committed_and_validated` |
| 3 | Scope Lock | Any list missing = reject | bounded allowlist |
| 4 | Package Layout | Brittle path = fail | explicit paths |
| 5 | Registry/Config Authority | duplicated authority = fail | preserve existing owner |
| 6 | Risk/Tier Policy | nondeterministic = fail | script-derived |
| 7 | Context Normalization | missing subject = fatal | includes resume proof |
| 8 | Input Acquisition | injection = fail | bounded input |
| 9 | Deterministic Planner | nondeterministic = fail | bundled script |
| 10 | Safe Executor | raw ambiguity = fail | runnable scripts |
| 11 | Evidence Enrichment | evidence lost = fail | one checkpointed commit per contract |
| 12 | Fail-Closed Evaluator | gap not blocking = fail | item completion proof gates commit |
| 13 | Workflow Architecture | duplication = fail | same-branch linear chain |
| 14 | Matrix/Parallel Execution | raw command = fail | normally N/A for focused item |
| 15 | Runtime Guarantee Preservation | unbounded setup = fail | no implicit install/bootstrap |
| 16 | Self-Modification Protection | silent relaxation = fail | unchanged |
| 17 | Schemas | missing schema = fatal | bundled JSON schemas |
| 18 | Test Contract | missing proof = fail | runnable completion proof |
| 19 | Failure Evidence | silent failure = fail | structured per stage |
| 20 | Documentation | unsupported claim = fail | target-aware semantics documented |
| 21 | Required File Manifest | MustNotAdd omitted = fail | scope-derived |
| 22 | Commit Plan | multi-commit/early push = fail | exactly one local commit, exact subject |
| 23 | Validation Commands | fake/inferred = fail | explicit target commands + item proof |
| 24 | Acceptance Criteria | vague = fail | binary evidence |
| 25 | Non-Goals Verification | not proven = fail | diff-proven |
| 26 | Required Validation Report | missing = HALT | include commit/delivery state |
| 27 | Definition of Done | missing = reject | committed + validated |
| 28 | Handoff | missing = reject | `<id> committed_and_validated` |
| 29 | Governance | authority ambiguity = reject | direct remote denied; terminal `make pr` only |

The `sections` manifest is generated by `compile_contract.py`; these semantics define what those
sections mean.
