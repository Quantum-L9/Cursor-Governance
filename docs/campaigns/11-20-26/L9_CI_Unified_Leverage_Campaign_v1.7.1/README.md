## Mission

Converge organization CI onto one central governance and execution architecture:
GitHub organization rulesets target consumers; `Quantum-L9/l9-ci-core` owns
orchestration, toolchain versions, requiredness, runner policy and release;
`Quantum-L9/l9-ci-sdk` owns capability discovery, provider execution and
canonical evidence. Retain native GitHub / SaaS operations as governed adapters
where necessary, not as competing policy authorities. Central defaults are
inherited at execution time for the promoted Core/SDK required runtime.
Consumers retain product code, real test commands, product constraints and
required native project bindings/thin callers. Existing CodeQL caller SHA pins
and managed native configuration generators remain until an explicitly admitted
compatible successor; this pack does not promise zero native caller updates.

Second, equally mandatory objective: derive the maximum defensible value from
all scanners and paid integrations in actual use. Confirm entitlements, activate
useful available capabilities, remove redundant expense and retain actionable
security, quality, and testing evidence. Do not buy or enable a new paid tier
without the operator's approval.

**v1.5.0 native-platform leverage:** `CODEQL_SONAR_LEVERAGE.md` binds actual
CodeQL/Sonar host scans, pricing/entitlement unknowns, exclusions, coverage
proof, existing #1062/#552 work, new-code quality gates and nonduplicative
test scheduling. The current CodeQL authority is deliberately not relocated.
