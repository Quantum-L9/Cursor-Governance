# Capability-Aware Adapters

Discover capability before prescribing execution.

## Tool-rich environment

Use targeted reads, searches, tests, or calculations tied to a named evidence gap. Record the decisive result, not routine tool narration.

## Tool-poor environment

Reason from supplied evidence, label limitations, and avoid claims that require unseen state.

## Parallel execution

Use true parallel trials only when all are true:

- isolated execution is supported;
- strategies are genuinely distinct;
- success criteria are measurable;
- coordination cost is lower than expected information gain.

Otherwise run sequential bounded probes. Do not assume a `Task` subagent, worktree, branch, or parallel runner exists.

## Git and writes

- Inspect Git state only when Git is available and relevant.
- Commit, push, open PRs, or modify external systems only with explicit authorization.
- Without authority, produce a decision record, implementation plan, patch proposal, or handoff.

## Domain Skill composition

A specific domain Skill owns domain law, validation, and output shape. This Skill adds only missing cross-domain reasoning and must not overwrite the domain contract.
