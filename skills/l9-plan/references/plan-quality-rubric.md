# Plan Quality Rubric

Quality is **not** scored by LLM taste. It is the set of gates in [plan-quality-gates.md](plan-quality-gates.md).

Informational dimensions (must still satisfy gates):

1. Falsifiable success criteria
2. Explicit out-of-scope
3. Dependency-ordered critical path
4. Grounded TODOs
5. Stress-test with disconfirming evidence
6. Leverage ranking
7. Rollback when high/irreversible
8. Doc/root surface honesty
9. Real final validation commands
10. Convergence honesty

Fail closed below gate completion — there is no partial "good enough" for readiness.
