# Transformation Report

## Preserved

- first-order leverage;
- evidence before assertion;
- disconfirming evidence;
- systematic debugging;
- alternatives and trade-offs;
- rollback and contingency awareness;
- document-corpus modes (ported and compressed).

## Replaced

- fixed Blocks 0-11 -> conditional proof obligations;
- overlapping mode taxonomies -> orthogonal router;
- mandatory visible reasoning -> concise evidence and decision ledger;
- arbitrary confidence percentages -> evidence-risk-action policy;
- assumed subagents and worktrees -> capability-aware adapters;
- checklist-only validation -> deterministic router fixtures and live benchmark contract.

## Corpus port

- `references/document-corpus-reasoning.md` restored as a load-on-demand corpus adapter;
- router `task_kind: corpus` and `output_profile: corpus_report` added with fixture coverage.

## Release posture

This pack is the canonical `l9-structured-reasoning`. The prior Block-protocol pack is deprecated.
Structural validators must pass. Empirical magnitude claims still require paired live runs under `references/benchmark-contract.md`.
