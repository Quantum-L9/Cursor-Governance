# Output Profiles

Choose the smallest profile that completes the task.

## answer

Use for a bounded question. Include the conclusion, decisive evidence, material caveat, and next action when needed.

## decision_record

Use for multi-option or high-stakes decisions. Include objective, options, criteria, evidence, selected option, trade-offs, reversibility, and reconsideration trigger.

## implementation_plan

Use before non-trivial implementation. Include scope, critical path, files or systems affected, validation, rollback, and Unknowns. Do not invent paths.

## architecture_record

Use for architecture choices. Include context, options, decision, consequences, migration, blast radius, and rollback.

## debug_report

Use for debugging. Include reproduction, observed evidence, hypotheses tested, root cause, minimal fix, regression test, and residual uncertainty.

## corpus_report

Use for multi-document corpus work. Include corpus scope, selected mode(s)/operations, dependency or pattern map, gaps with severity, coherence conflicts with source pairs, actionable insights, and readiness (`Yes` / `No` / `Partial`). Cite documents for material claims.

## machine-readable ledger

Attach or emit the ledger only when handoff, resumability, run comparison, or formal auditability materially helps. Do not force it into every response.
