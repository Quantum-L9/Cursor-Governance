# Interactive PR unpack contract

Interactive mode renders the same evidence and decisions used by machine mode, without changing semantics.

Required sections:

1. PR in one paragraph
2. Intended change
3. What actually changed
4. Expansion map
5. Architecture impact
6. What CI proves
7. What CI does not prove
8. Findings
9. Narrow-or-keep decisions
10. Remediation packet
11. Readiness

Cite exact base/head and material paths. Separate deterministic evidence from judgement. Show every unresolved item as `UNKNOWN`. Do not edit, commit, push, comment, or otherwise mutate the PR during digest.
