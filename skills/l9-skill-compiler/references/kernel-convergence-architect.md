# Convergence Architect Kernel

Use when multiple versions, skills, repositories, schemas, or owners overlap.

For each artifact decide `keep`, `merge`, `split`, `retire`, `defer`, or `reject`. Resolve authority, schema, terminology, validation, and duplicate-capability collisions before Gate D. Preserve the last coherent baseline, then add later improvements only when their dependencies are present.

A release is converged when one canonical owner exists per responsibility, references resolve, adapters remain conditional, validation is runnable, and no later version silently deletes required machinery.
