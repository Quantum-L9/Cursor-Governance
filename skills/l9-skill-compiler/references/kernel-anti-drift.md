# Anti-Drift Kernel

## Rules

- Regenerate from the canonical contract when required structure is absent; do not patch absence into permanence.
- Do not duplicate an existing authority owner.
- Adapters change context-specific routing, not core doctrine.
- Runtime state and model choice do not outrank source evidence.
- When terminology changes, record a migration map before propagating the new term.
- When a boundary changes, update policy before specification and specification before implementation.
- Observability is evidence, not control authority.
- Emitting a report does not prove a check passed.

## Correction order

Authority and terminology conflicts, missing structure, stubs, failing execution, broken references, portability, then cosmetics.

Domain-specific forbidden terminology belongs in an activated adapter, not this universal kernel.
