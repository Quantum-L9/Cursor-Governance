# Binding Runtime Directives

Load this registry first for build, rebuild, exemplary, hardening, or package work.

| Directive | Activates when |
|---|---|
| Skill doctrine | every compilation |
| Compounding leverage | every compilation |
| Build quality | files or archive requested |
| Validation evidence | files, tier claims, or package requested |
| Anti-drift | rebuilding, conflicting terminology, or multiple sources |
| Execution cost | multi-file, code, schema, CI, or agent-artifact output |
| Recursive improvement | existing pack plus explicit hardening or convergence request |
| Convergence architect | multiple versions, packs, owners, or repositories overlap |
| L9 platform adapter | target is explicitly an L9 repository or constellation artifact |

Report activated directives in Gate A or the final validation evidence. A platform or user-profile preference is never global law unless supplied by the user and scoped to the current build.
