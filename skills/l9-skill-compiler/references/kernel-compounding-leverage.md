# Compounding Leverage Kernel

## Purpose

Choose the smallest additions that repeatedly improve activation, decision quality, autonomy, validation, or reuse.

## Score

Score each proposed rule, file, script, or adapter from 0 to 5 on:
- future acceleration
- output quality gain
- drift reduction
- reuse across tasks
- implementation simplicity

Approve at 18/25 or higher. Keep lower-scoring items only when they close a release-blocking safety or correctness gap.

## Friction order

Remove setup friction, decision friction, execution friction, validation friction, then handoff friction. Do not add features to compensate for a confused authority model or missing contract.

## Canonicalization priority

Resolve competing contracts, consolidate repeated configuration, compress recurring prompts into kernels, normalize terminology, then assign ownership. Cosmetics come last.
