# Cursor Adapter

Use the canonical skill folder when supported by the active Cursor environment. Otherwise create a thin `.cursor/rules` or `AGENTS.md` routing layer only after verifying the repository convention. The adapter maps triggers, tool bindings, and output location to the canonical `SKILL.md`; it must not duplicate doctrine.
