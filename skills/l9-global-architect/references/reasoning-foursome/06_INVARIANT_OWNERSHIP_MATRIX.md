# L9 Reasoning Foursome Invariant Ownership Matrix

## 1. Purpose

Prevent semantic collision across First-Order, Second-Order, Leverage, and Signal Leverage.

If two components appear to own the same concern, the architecture is drifting.

## 3. Collision Tests

### Collision A: Signal Leverage selects an intervention
Violation: Signal Leverage absorbs First-Order.

Repair: return evidence to First-Order.

### Collision B: Signal Leverage invents consequences
Violation: Signal Leverage absorbs Second-Order.

Repair: preserve and route only observed/predicted consequence evidence.

### Collision C: Signal Leverage assigns systemic value
Violation: Signal Leverage absorbs Leverage.

Repair: return topology and propagation evidence to Leverage.

### Collision D: Leverage owns routing mechanics
Violation: Leverage absorbs Signal Leverage.

Repair: Leverage identifies valuable gain and eligible beneficiary class; Signal Leverage determines the governed propagation path.

### Collision E: Closed-loop topology is treated as leverage by itself
Violation: topology theater.

Repair: require changed future behavior and Leverage evaluation.

### Collision F: Write-back silently rewrites authority
Violation: signal propagation becomes governance theft.

Repair: distinguish observation, challenge, recommendation, promotion candidate, and owner-accepted promoted change.

## 4. Complementarity Test

```text
First-Order
  -> gives Second-Order a precise intervention

Second-Order
  -> gives Signal Leverage evidence-bearing consequence surfaces

Signal Leverage
  -> preserves/routes those surfaces to Leverage

Leverage
  -> determines systemic value and reusable shared gains

Signal Leverage
  -> propagates validated learning to eligible consumers

Future First-Order / Second-Order / Leverage
  -> begin from a stronger evidence baseline
```

The foursome is healthy when each component strengthens the others while retaining one semantic owner per concern.
