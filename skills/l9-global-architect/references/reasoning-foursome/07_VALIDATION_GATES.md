# L9 Reasoning Foursome Validation Gates

## Gate 1: First-Order Causal Compression

PASS only when the objective, governing cause, owner, decisive intervention, eliminated work, residual work, assumptions, unknowns, and disconfirming evidence are explicit enough for the next stage.

FAIL when the result is a prioritized task list rather than causal compression.

## Gate 2: Second-Order Predictive Consequence Surface

PASS only when material predicted consequences, affected participants, uncertainty, timing, reversibility/path dependence, and evidence are represented without leverage scoring.

## Gate 3: Signal Leverage Prediction Routing

PASS only when material prediction evidence preserves required meaning and has a justified path to Leverage.

Check:

- evidence/provenance/context preserved;
- no authority theft;
- topology no more complex than necessary;
- branches add non-redundant value;
- predicted signal drag visible.

## Gate 4: Predicted Leverage

PASS only when leverage claims are grounded in Second-Order evidence delivered through valid signal receipts and local benefit is separated from systemic benefit.

## Gate 5: Second-Order Observed Consequence Surface

PASS only when observed results, downstream effects, causal attribution, prediction delta, contradictions, and unpredicted effects remain distinct from the prediction.

## Gate 6: Signal Leverage Observation Routing

PASS only when observed evidence reaches Leverage with meaning preserved and signal topology receipts distinguish:

- one-way;
- bidirectional;
- closed-loop;
- mesh.

Loops that merely echo unchanged information FAIL.

## Gate 7: Realized Leverage

PASS only when actual evidence supports systemic improvement, drag is included, predicted and realized leverage remain distinct, and shared gains identify eligible beneficiary classes.

## Gate 8: Signal Leverage Write-Back

PASS only when validated shared gains are propagated with:

- eligibility controls;
- evidence-bound promotion;
- semantic owner acceptance for durable changes;
- deduplication/novelty controls;
- bounded recursion;
- convergence receipts;
- observable future behavior change or an explicit propagation gap.

Storage alone FAILS.

## Gate 9: Topology Integrity

PASS only when topology complexity is earned.

- One-way is sufficient unless return value exists.
- Bidirectional requires useful non-redundant return flow.
- Closed-loop requires changed state and future behavior.
- Mesh requires useful branch/fan-out/reconvergence or productive subloops.

Connectivity theater FAILS.

## Gate 10: Semantic Non-Collision

PASS only when:

- First-Order owns intervention selection;
- Second-Order owns consequence modeling;
- Leverage owns systemic value, rank, score, fingerprint, and compounding;
- Signal Leverage owns propagation semantics and write-back transport;
- durable authority changes remain with their semantic owner.

Any duplicate semantic owner FAILS.

## Gate 11: Foursome Self-Leverage

The reasoning architecture must demonstrate its own leverage:

- First-Order eliminates unnecessary work.
- Second-Order improves prediction and causal learning.
- Leverage converts outcomes into systemic value and reusable gains.
- Signal Leverage makes those gains safely reachable by eligible consumers.

If Signal Leverage merely creates more events, messages, callbacks, or loops without improving future reasoning, it is negative leverage and must be simplified.
