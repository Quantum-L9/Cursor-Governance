# L9 Reasoning Foursome Pack v1.0.0

This pack evolves the L9 Reasoning Triad into four first-class reasoning primitives with explicit semantic ownership.

## The Foursome

1. **First-Order Thinking**
   - Owns governing cause and intervention selection.
   - Cardinal question: what one change makes the greatest amount of other work unnecessary?

2. **Second-Order Consequence Lens**
   - Owns predicted and observed consequence surfaces.
   - BEFORE: what changes IF we do it?
   - AFTER: what changed BECAUSE we did it?

3. **Leverage Kernel**
   - Owns systemic value, predicted/realized/compounded leverage, rank, score, fingerprint, and mesh-value improvement.

4. **Signal Leverage Kernel**
   - Owns evidence-bearing signal movement, meaning preservation, routing topology, branching, reconvergence, eligibility, write-back, and bounded signal loops.
   - Treats one-way, bidirectional, closed-loop, and multi-directional spiderweb/mesh leverage as first-class propagation topologies.

## Why the Fourth Primitive Exists

Leverage and Signal Leverage solve different problems:

```text
Leverage:
  Is this valuable?
  How much systemic advantage exists?
  What should become reusable?

Signal Leverage:
  How does the evidence or learning move?
  Who is eligible to receive it?
  What topology is justified?
  How does it reconverge?
  How does write-back preserve authority?
  How does the loop converge?
```

A valuable learning that cannot reach future consumers is trapped leverage. A highly connected signal mesh carrying no useful learning is noise.

## Canonical Mental Model

```text
FIRST-ORDER
  selects intervention
       ↓
SECOND-ORDER
  predicts / observes consequences
       ↓
SIGNAL LEVERAGE
  preserves + routes evidence
       ↓
LEVERAGE
  evaluates systemic value
       ↓
SIGNAL LEVERAGE
  propagates validated learning
       ↓
stronger future baseline
```

Signal Leverage is cross-cutting, not merely a fourth serial box. It governs the propagation plane that links reasoning, learning, and the wider L9 leverage mesh.
