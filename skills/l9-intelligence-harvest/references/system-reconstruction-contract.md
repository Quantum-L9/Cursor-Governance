# System Reconstruction Contract

Reconstruct the donor as a system, not a file list.

## Required output

Produce evidence-grounded identity, workflows, data/control flow, ownership boundaries, upstream/downstream dependencies, and current authority surfaces relevant to the harvest target.

## Evidence precedence

1. Observable current executable behavior.
2. Executable/current contracts.
3. Generated current artifacts.
4. Current documentation.
5. Legacy documentation.

When sources conflict, preserve the conflict and select the strongest observable current authority. Resolve wrappers, aliases, indirection, and launchers to what they actually invoke before claiming behavior. A name alone is not evidence.

Classify each material statement as CONFIRMED, INFERENCE, or UNKNOWN. Do not manufacture missing behavior to complete the picture.
