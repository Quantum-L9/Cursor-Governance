# Priority and leverage

Eligibility before value: authority, locked restrictions, true prerequisites, available resources and risk. Compare critical path, reachable downstream unlock, time to proof, marginal cost, reusable benefit, information gain, reversibility, urgency, resource collision and operator attention. Avoid invented ROI, exact probabilities and counting graph edges as benefit. Include the strongest feasible alternative and a counterfactual that would reverse the choice.

Keep separate: strategic importance; immediate operator attention; current execution status; eligibility; independent parallel work; parked wake triggers. One protected primary does not imply one active lane. For concurrent work, inspect shared worker, runtime, database, secrets, approvals and scarce operator capacity rather than accepting a self-declared independence label. A single high-value consumer may outweigh multiple low-value consumers.

Readiness is evidence-ordinal: unknown -> defined -> source present -> local verified -> integrated -> hosted -> operating -> outcome proven. Assess named deliverable/version; never compute a percent from these stages. Report immediate blocker, cheapest authorized discriminating test, unlock, confidence and next review trigger.

## Phase-change propagation
When an interface or owner changes, inspect each dependent stage and consumer: predecessor, proof, transport, operational ownership, cutover, rollback and future admission. Remove a false prerequisite from every affected projection. A later optional interface must not block an earlier useful product. Do not silently change immutable accepted commitments.

## Opportunity census and decision
Candidate census = relevant active + blocked + parked + discovered sibling lanes. Report selection boundaries and uninspected coverage. Compare candidate with best alternative and counterfactual using source-grounded benefit, time, risk and scarcity. Keep an explicit wake condition for each parked lane. Do not make claimed portfolio coverage from a self-authored short list.
