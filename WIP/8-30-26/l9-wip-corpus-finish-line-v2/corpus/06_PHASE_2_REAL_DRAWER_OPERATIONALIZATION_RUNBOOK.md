# Phase 2 - Real Drawer Operationalization Runbook

## Objective
Move from a proven 25-75 artifact pilot to one real WIP drawer containing hundreds of artifacts, with no architecture redesign.

## Steps
1. Freeze the three proven repository SHAs and packet/policy versions.
2. Preserve Phase 1 inputs, expected topology, publication disposition, memory receipts, and retrieval answers as golden fixtures.
3. Select one real Dropbox drawer with mixed WIP, versions, TODOs, specs, archives and duplicates.
4. Run full verified acquisition, topology compile, publication preflight/apply, projection, replay and retrieval.
5. Execute delta scenarios: add, edit, rename, remove, retraction, supersession, duplicate introduction, conflicting declaration.
6. Verify temporal lifecycle and projection withdrawal for facts that cease to be current.
7. Compile WorkContextPacket for three real objectives.
8. Compile CandidateWorkUnits and a BuildWavePlan.
9. Compare planner output to expert manual judgment before handing to Program Execution.

## Pass criteria
- source coverage explained
- no unexplained identity churn
- no stale ACTIVE truth after retraction
- minimum-context retrieval is materially smaller than the drawer
- required dependencies/blockers are present
- superseded noise is compressed, not injected wholesale
- BuildWavePlan obeys dependency order and exposes parallel work
