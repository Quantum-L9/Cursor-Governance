# Mission Lock

## Objective
Create a repeatable operating system for turning accumulated WIP into an evidence-backed build strategy that maximizes downstream leverage.

## Inputs
- one or more Dropbox WIP roots
- current repository/objective context
- source files, archives, roadmaps, TODOs, plans, specs, code packs, contracts, research, and duplicate/superseded material

## Outputs
1. trustworthy artifact/corpus observations
2. validated topology
3. governed durable memory + graph projection
4. task-scoped minimum sufficient context
5. bounded evidence-backed WorkUnits
6. leverage-ranked, dependency-correct BuildWavePlan
7. Program Execution handoff

## Non-goals
- automatic file deletion/consolidation
- priority scores fabricated by l9-meta-injector or topology
- direct Graphiti writes from producers
- a second execution runtime
- letting semantic similarity masquerade as dependency truth
