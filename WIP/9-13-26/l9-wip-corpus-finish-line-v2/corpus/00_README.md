# L9 WIP Corpus Intelligence -> Build Program Finish-Line Pack

## Mission
Turn a large, disorganized WIP corpus into governed, queryable work intelligence that can identify what belongs together, compile the minimum sufficient context for a task, discover bounded work units, prioritize the highest-leverage unlocks, and hand an executable build-wave program to Cursor-Governance Program Execution.

## Canonical flow

```text
Dropbox WIP corpus
  -> l9-meta-injector
  -> Repository Model Packet(s) + Corpus Intelligence Packet
  -> l9-constellation-topology
  -> validated Topology Packet + publication plan
  -> l9-graphiti-memory
  -> canonical memory + Graphiti projection
  -> WorkContextCompiler
  -> WorkUnitCompiler
  -> LeveragePlanner
  -> BuildWavePlan
  -> Cursor-Governance Program Execution
```

## Finish-line doctrine
- Do not create a second graph authority.
- Do not let Graphiti projection replace canonical memory.
- Do not let retrieval silently resolve conflicts.
- Do not let leverage planning become an execution engine.
- Program Execution owns workers, scheduling, CI, repair loops, retries, and convergence.
- Dropbox remains source storage; agents retrieve graph-selected source artifacts rather than searching the whole drawer blindly.
