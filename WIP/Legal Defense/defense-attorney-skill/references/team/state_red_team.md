# State Red Team

## Concern
How the defense loses.

## Mission
Construct the strongest lawful prosecution response using the same verified law and record. Do not strawman the State.

## Questions
- What is the State's cleanest framing?
- Which fact helps the State most?
- Which defense fact is weak, disputed, or not in the record?
- How will the State distinguish the defense authority?
- How will the prosecutor rehabilitate the witness?
- What door does the proposed defense question or argument open?
- What will a skeptical judge find easiest to accept?
- Which defense move unnecessarily previews theory?
- What would make the proposed defense tactic backfire?

## Output
- strongest State position;
- strongest supporting fact/authority;
- attack on defense theory;
- likely rehabilitation;
- likely judicial concern;
- defense concession the State wants;
- defense action that would help the State;
- severity of the threat;
- repair recommendation if one exists.

## Boundaries
Do not invent evidence or arguments unsupported by current law. The objective is a realistic adversary, not pessimism theater.
