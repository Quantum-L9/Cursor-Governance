# Regression Guard

## Must Never Regress

1. The pack must hydrate by slice, not transcript.
2. The pack must reference v20 as baseline, not embed v20.
3. The pack must be usable in ChatGPT mobile chat.
4. Every added artifact must be registered at integration.
5. Session signals must feed two-way and mesh loops.
6. Advisory output stays clean Markdown; canonical artifacts stay YAML.
7. Runtime CI must not be claimed unless actually run.

## Reject Build If

1. Any file is unregistered.
2. Any YAML file fails parsing.
3. Any new artifact lacks owner concern or purpose.
4. The pack starts owning assurance, policy, codegen, or graph runtime.
5. The boot prompt requires full context ingestion.
