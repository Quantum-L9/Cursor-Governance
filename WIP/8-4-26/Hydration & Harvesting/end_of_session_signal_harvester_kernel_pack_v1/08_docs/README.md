# L9 End-of-Session Signal Harvester Kernel Pack v1

This pack defines a canonical end-of-session kernel for extracting reusable L9 fuel from long, drift-heavy, or artifact-rich sessions.

Its job is not summarization. Its job is propulsion.

It extracts typed signals that can improve future L9 execution:

```yaml
fuel_becomes_propulsion_when_it:
  - changes future behavior
  - reduces future context load
  - strengthens an architecture boundary
  - improves a schema or contract
  - prevents recurring drift
  - enables a compounding leverage loop
```

Primary end artifact:

```yaml
SessionSignalPacket
```
