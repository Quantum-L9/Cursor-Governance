# Approvals, Waivers, and Handoff

An approval grants one exact action under one exact state. A waiver excuses one scoped gate obligation under compensating control. Neither may widen the Blueprint authorization ceiling.

**Cosmetic / advisory CI disable or demotion** (e.g. meta-header requirements) is a **Phase 0 preflight authority act**, recorded in `PHASE0_USER_CONFIG.yaml` blocking inventory and an expiring `program_ci_advisory` waiver. It is not mid-flight improvisation.

Routine push/PR remediation approvals may be pre-authorized in Phase 0 with expiry bound to the program digest. Mid-flight human asks remain for business DEC-*, merge, publish, deploy, and destructive actions.

The Controller Handoff Receipt summarizes runtime evidence and recommends a program verdict. Only the program owner may accept the terminal verdict or issue a superseding Blueprint.
